# dystymis — сеть сайтов с советами

**dystymis** — независимая сеть из 5 русскоязычных информационных сайтов, размещённая на GitHub Pages. 246 статей о быте, здоровье, авто, даче и отношениях. Каждый сайт — отдельный репозиторий и отдельный поддомен.

Хаб сети (с индексом всех разделов): https://dystymis.github.io/

## Как устроен проект

- Статическая генерация: движок на Node.js собирает 246 HTML-страниц из markdown/JSON.
- Хостинг: GitHub Pages (HTTPS, CDN).
- Индексация: sitemap.xml + IndexNow (Яндекс/Google/Bing).
- Разметка: Schema.org JSON-LD (Article, FAQPage, BreadcrumbList, WebSite).
